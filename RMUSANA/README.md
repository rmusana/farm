# RMUSANA Poultry Management & Investment Platform

Integrated operations + investment intelligence for the LUK54 dedicated flock of 2,500 layer birds (JALO DREAM FARM × LUK54 Agreement).

## Stack

- **Frontend:** HTML5, CSS3, Vanilla JS (ES modules), Chart.js, Lucide, PWA
- **Backend:** Google Apps Script Web App
- **Data:** Google Sheets
- **Files:** Google Drive
- **Mail:** Gmail (Apps Script)
- **Host:** GitHub Pages

## Quick start (local)

```bash
cd RMUSANA
npx serve .
# open http://localhost:3000
```

Sign in with bootstrap accounts (see `DEPLOY.md`).
